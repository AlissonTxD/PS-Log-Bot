## ⚔️ O QUE É ISSO?

O **ARK Log Bot** é um sistema que:

- 📸 Captura automaticamente eventos do log do jogo
- 🧠 Usa OCR (Tesseract) para ler a tela
- 📡 Envia alertas direto para o Discord
- 🚨 Ajuda sua tribo a reagir rápido a ataques

Se algo acontecer…  
VOCÊ VAI SABER.

---

## 🖥️ Interface

- 🎯 Seleção de resolução
- 🧪 Modo Teste
- ▶️ Botão START
- ⛔ Botão STOP
- 🔍 Verificação automática do Tesseract

Interface feita em **PyQt5** com arquitetura organizada (MVVM).

## 🧠 COMO FUNCIONA

1. O bot captura uma área específica do jogo
2. Trata a imagem
3. Extrai o texto via OCR
4. Detecta eventos relevantes
5. Envia alerta no Discord automaticamente

Zero intervenção manual.
